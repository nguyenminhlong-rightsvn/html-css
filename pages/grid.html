Thực hành bố cục với CSS Grid

Grid là mô hình bố cục hai chiều: chia hàng và cột cùng lúc. Đặt display: grid cho phần tử cha (grid container), mọi con trực tiếp trở thành grid item.

Khác biệt với Flexbox: Flexbox xếp item theo một chiều (hàng hoặc cột). Grid vẽ sẵn khung lưới hai chiều rồi xếp item vào. Bố cục cả trang → Grid. Sắp một hàng nút, một navbar → Flexbox.

Tổng kết

Đặt trên container:

  • display: grid — bật grid
  • grid-template-columns / grid-template-rows — vẽ khung lưới
  • gap / row-gap / column-gap — khe giữa ô
  • justify-items / align-items — canh nội dung trong ô
  • justify-content / align-content — canh cả lưới trong container

Đặt trên item:

  • grid-column / grid-row — vị trí theo vạch, hoặc span n
  • justify-self / align-self — ghi đè canh lề

Grid làm bố cục hai chiều. Hai cái không loại trừ nhau: thường dùng Grid cho khung trang, rồi Flexbox bên trong từng ô.
